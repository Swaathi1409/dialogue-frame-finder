Discovery - ffmpeg binary name bug (Phase 1)

what I typed:
nothing - found while wiring yt-dlp

what happened:
imageio_ffmpeg names the binary ffmpeg-win-x86_64-v7.1.exe. yt-dlp
looks for plain ffmpeg.exe in the given directory and doesn't find
the versioned name. fixed by copying the bundled binary to a temp
dir with the plain name once per process.

Discovery - PaddleOCR 3.7.0 crashes on Windows CPU (Phase 3)

what I typed:
nothing - found while probing the new API

what happened:
pip installed PaddleOCR 3.7.0 (latest) instead of the 2.7.x line
the brief meant. three problems with 3.7.0: ocr() is deprecated,
cls=True argument rejected, and the paddle static runner crashes with
NotImplementedError from the oneDNN backend on Windows CPU. the error
is at the inference engine level, not fixable in application code.
pinned to paddleocr==2.7.3 + paddlepaddle==2.6.2 which is stable.
updated requirements.txt with a comment explaining why.
